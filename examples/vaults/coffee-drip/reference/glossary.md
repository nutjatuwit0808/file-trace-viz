# ศัพท์เฉพาะ (Glossary)

- **[[extraction]]** — กระบวนการละลายสารประกอบออกจากผงกาแฟด้วยน้ำร้อน
- **[[bloom]]** — ขั้นตอนเทน้ำปริมาณน้อยก่อนเพื่อไล่ก๊าซ
- **[[brew-ratio]]** — สัดส่วนน้ำหนักน้ำต่อน้ำหนักกาแฟ
- **TDS (Total Dissolved Solids)** — เปอร์เซ็นต์สารที่ละลายอยู่ในน้ำกาแฟ วัดด้วยเครื่อง refractometer เพื่อบอกความเข้มข้น
- **[[roast-level]]** — ระดับความร้อน/เวลาที่ใช้คั่วเมล็ดดิบ
- **[[origin]]** — แหล่งปลูกเมล็ดกาแฟ

ดูภาพรวมทั้งหมดได้ที่ [[index]] หรืออ่านที่มาของอุปกรณ์และวิธีชงแบบนี้ได้ที่ [[brewing-history]]
