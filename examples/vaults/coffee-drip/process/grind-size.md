# ขนาดผงกาแฟ (Grind Size)

กำหนดโดย [[grinder]] มีผลต่อความเร็วที่น้ำไหลผ่านผงกาแฟ และพื้นที่ผิวสัมผัสระหว่างน้ำกับกาแฟ

- **บดหยาบ** (coarse) — น้ำไหลเร็ว สัมผัสน้อย เสี่ยงสกัดไม่พอ ([[sour-taste]], [[weak-body]])
- **บดละเอียด** (fine) — น้ำไหลช้า สัมผัสมาก เสี่ยงสกัดเกิน ([[bitter-taste]]) หรือถึงขั้น [[clogged-filter]]

pour-over ทั่วไปใช้ความหยาบระดับ "ปานกลาง" ใกล้เคียงเกลือทะเลหยาบ ปรับละเอียด/หยาบทีละนิดแล้วชิมผลเทียบกับ [[extraction]] ที่ได้ในแต่ละรอบ
