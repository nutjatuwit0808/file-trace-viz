# การสกัด (Extraction)

กระบวนการที่น้ำร้อนละลายสารประกอบต่างๆ ออกจากผงกาแฟ — กรด น้ำตาล และสารขม ละลายออกมาตามลำดับความเร็วต่างกัน ทำให้ "ระดับการสกัด" เป็นตัวแปรกลางที่ [[brew-ratio]], [[water-temperature]], [[grind-size]] และ [[timing]] ล้วนส่งผลถึง

- **สกัดน้อยเกิน (under-extraction)** → รสเปรี้ยวนำ ขาดความหวาน → ดู [[sour-taste]]
- **สกัดมากเกิน (over-extraction)** → รสขมนำ ฝาดค้างลิ้น → ดู [[bitter-taste]]
- **สกัดพอดี** → หวาน กรดสมดุล มี body ชัดเจน ตรงข้ามกับ [[weak-body]]

เมล็ดกาแฟที่ [[roast-level|คั่วต่างระดับ]] ก็สกัดง่ายยากต่างกัน เป็นอีกตัวแปรที่ต้องคุมคู่กับตัวแปรการชง
