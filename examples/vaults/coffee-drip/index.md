# ดริปกาแฟ — Map of Content

Vault ตัวอย่างสำหรับ FileTraceViz อธิบายการทำงานของการดริปกาแฟแบบ pour-over ทั้งระบบ ตั้งแต่อุปกรณ์ ขั้นตอนชง ไปจนถึงการแก้ปัญหารสชาติ

## เริ่มจากตรงนี้

- อยากรู้จักอุปกรณ์ก่อน → [[dripper]]
- อยากเข้าใจขั้นตอนชงทั้งหมด → [[pour-technique]]
- อยากรู้ว่าอัตราส่วนน้ำ:กาแฟควรเท่าไหร่ → [[brew-ratio]]
- เมล็ดกาแฟมีผลกับรสชาติยังไง → [[roast-level]]
- ชงออกมาแล้วรสไม่ดี → [[bitter-taste]] หรือ [[sour-taste]]
- ศัพท์ที่ไม่คุ้น → [[glossary]]

## โครงสร้าง vault

- `equipment/` — อุปกรณ์ที่ใช้ดริป
- `process/` — ขั้นตอนและตัวแปรการชง
- `beans/` — เรื่องเมล็ดกาแฟ
- `troubleshooting/` — แก้ปัญหารสชาติที่พบบ่อย
- `reference/` — ศัพท์และประวัติ
